### 5.2 우리에게만 있는 것

- **단일 기능으로는 없다.** 위 기능은 모두 하는 서비스가 있다.
- **확인하지 못한 것** (유일하다는 근거는 아니다)
  - **대화가 끝난 뒤** 사용자가 한 말을 하나씩 모아, 원래 표현 → 자연스러운 표현과 함께 읽기·한국어 번역·설명을 **한 번에 묶어 주는** 피드백. 교정은 똑톡이 대화 중에 바로 하고, 번역·읽기는 Amiko가 메시지마다 주지만, 둘을 대화 후 하나의 피드백으로 묶는 형태는 찾지 못했다.
  - 대화 상대의 **성격까지 사용자가 자유롭게** 정하는 설정. 정해진 캐릭터나 상황 중에서 고르는 곳은 있다(TalkMe는 분위기까지 설정한다고 소개하나 원문 미확인).

## 6. 피드백 시점 선행 연구: 대화 중 즉시 교정 vs 대화 후 피드백

조사: Codex(학술 검색) + Claude(핵심 논문 원문 확인). 검증 대상은 decisions.md 2026-11-03 "대화 후 피드백" 결정의 이유(기획자의 경험)다.

### 6.1 결론

- **어느 한쪽이 늘 더 효과적이라는 근거는 없다.** 말하기 과제에서 즉시 교정이 유리했던 연구도, 차이가 없던 연구도, 지연이 유리했던 연구도 있다.
- 직접 비교 연구를 모은 체계적 문헌고찰(20편)에서는 즉시 우세가 가장 많았고(본문 기준 10편), 차이 없음 7편, 지연 우세 3편이다. 저자 결론은 "즉시가 지연보다 더 효과적이거나 같다"이다. 지연 우세 3편은 모두 무피드백 대조군이 없었다. ✅
- **AI 챗봇과의 자유 대화를 직접 비교한 연구**에서는 대화 중 교정과 대화 후 요약 교정의 문법 점수 차이가 유의하지 않았다. 다만 **대화 중 교정 집단만 "효과적이다"라는 인식이 유의하게 올랐다.** ✅
- 컴퓨터 기반 학습 전반의 메타분석(51개 연구)에서도 즉시·지연 간 평균 차이는 유의하지 않았다(g=0.03). 🔎

### 6.2 가설별 판정

| 가설 (기획자의 경험) | 판정 |
|---|---|
| 1. 대화 중에는 교정 없이 흐름에 집중하는 게 낫다 | 흐름을 지키자는 교수 관점은 있으나, 학습 효과가 지연 쪽으로 낫다는 근거는 혼재 |
| 2. 대화 후 복기하며 읽어야 학습된다 | 대화 후 리포트를 읽는 것만으로 즉시보다 학습이 낫다는 직접 근거는 찾지 못함. 피드백 뒤 **다시 연습(재시도)**하게 한 연구에서는 직후 효과가 관찰됨 🔎 |
| 3. 즉시 교정은 초급자에게 편하지만 중상급자에겐 덜 필요하다 | 저수준 학습자에게 즉시 교정이 더 효과적이었다는 연구 1편이 있다 ✅(문헌고찰 요약). "중상급자는 덜 필요하다"를 입증한 연구는 없다. 문헌고찰 저자도 숙련도별 차이를 앞으로 연구할 과제로 남겼다 ✅ |
| 4. 즉시 교정은 이해했다고 넘어가 같은 실수를 반복하게 한다 | "그 자리에서 고친 반응만으로 습득을 판단할 수 없다"는 점은 타당하다. 하지만 즉시 교정이 반복 오류를 늘린다는 직접 근거는 없다. AI 챗봇 연구에서 세션별 오류 수는 조건에 따라 유의하게 다르지 않았다 ✅ |

### 6.4 한계

- 대부분 영어 학습, 청소년·대학생, 문법 항목 대상이다. **한국인 성인이 AI와 일본어로 음성 대화하는 상황을 직접 비교한 연구는 찾지 못했다.**
