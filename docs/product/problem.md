# 문제 정의

근거: [raw-notes.md](raw-notes.md) 2026-11-02. 모든 내용은 기획자가 직접 겪은 일(관찰)이다.

| 칸 | 내용 |
|---|---|
| 누가 | 일본어를 어느 정도 구사하는 학습자. **A**: 아직 조금 서툴러서 연습하고 싶은 사람. **B**: 말하는 건 어렵지 않지만 실력이 녹슬지 않게 관리하고 싶은 사람 |
| 언제 | **A**: 실력을 기르고 싶을 때. **B**: 일본어를 까먹지 않게 연습하고 싶을 때 |
| 무엇을 하려다 | 실제로 일본어로 대화하며 회화를 연습하려 한다 |
| 어디서 막히나 | 연습 상대를 구할 수 없다. 한국에 살면서 일본인 친구를 만들기 어렵다. 회화 모임은 매일 할 수 없고, 매주 오프라인으로 모여야 하며, 장소가 멀면 가기 힘들고 시간이 많이 든다. **A**는 실제 사람과 대화하는 게 부끄럽다. 일본인과 대화하면 조금 틀리게 말해도 원어민은 알아듣기 때문에, 하나하나 교정해 주거나 지적해 주지 않는다 |
| 지금은 어떻게 버티나 | 오프라인 회화 모임에 나가거나 일본어 영상을 보며 따라 한다. 하지만 영상은 직접 대화하는 게 아니라 따라 하는 것이고, 영상 속 흐름에 맞출 수밖에 없다 |

## 열린 질문

- 면접 회화는 위 문제 정의에서 어떤 문제를 푸는 기능인가. 기획자가 취업 준비생이라 넣은 기능이고, 일반 회화와 나눈 이유가 아직 명확하지 않다. 이번 범위에서는 기능을 그대로 둔다.
